About This System

The Cloud-Based Attendance Management System is designed to automate and simplify the process of tracking student attendance using modern web technologies and AI.

✨ Key Features

  • ✔ Face Recognition-based attendance marking
  • ✔ Secure Firebase Authentication
  • ✔ Role-based access (Admin, Lecturer, Student)
  • ✔ Real-time data storage using Firestore
  • ✔ Attendance analytics and reports
  • ✔ Cloud-based image storage

👨‍💻 How It Works

  • 📌 Students enroll in courses and upload reference photos
  • 📌 Lecturers upload class images
  • 📌 System detects faces and marks attendance
  • 📌 Data is stored and analytics are generated

🎯 Benefits

  • ✔ Eliminates manual attendance
  • ✔ Reduces proxy attendance
  • ✔ Saves time for lecturers
  • ✔ Provides accurate reports

🚀 Use Cases

  • 🏫 Colleges and Universities
  • 🎓 Training Institutes
  • 📚 Coaching Centers
